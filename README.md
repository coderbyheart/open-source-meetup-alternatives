## Table Keys

### ¹: Maturity

| Maturity   | definition                                                  |
| ---------- | ----------------------------------------------------------- |
| _mature_   | the project is actively used by groups                      |
| _new_      | this project is new or in-development, with no usage (yet!) |
| _inactive_ | was under development, but more than 1 year without commits |

### ²: Technologies

For most projects, when a programming language is listed, it's referring to the primary language used for the server-side (backend) used by the project.
